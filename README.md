# MoveCS

MoveCS è l’app che ti mostra tutte le fermate e gli orari dei bus di Cosenza in modo semplice e veloce. Consulta la mappa, trova le fermate vicine, guarda le prossime corse e pianifica i tuoi spostamenti in pochi secondi. Tutto ciò che ti serve per muoverti in città, sempre a portata di mano
